# MDP
This project focuses on developing a multiple disease prediction system capable of forecasting the likelihood of heart disease, diabetes, and liver disease using two distinct machine learning models: Random Forest Regressor, Linear Regression. The system leverages publicly available datasets to train and validate each model, ensuring accuracy and reliability. The datasets undergo preprocessing, including normalization, feature selection, and handling missing values, to enhance the predictive performance of the models. Each model is then evaluated using metrics such as accuracy score to compare their effectiveness in predicting the diseases. A user-friendly interface is developed using a web framework, allowing users to input relevant medical data and receive predictions regarding their risk of developing heart disease, diabetes, or liver disease. The final system aims to assist healthcare professionals and patients in making informed decisions by providing an early warning system for these conditions.
